# Third-party UI code

`src/components/CopyButton.tsx` adapts Viora UI's [Copy Button](https://www.vioraui.dedyn.io/docs/components/copy-button).

The adaptation retains its copy feedback states, reset timer, reserved label width, and check icon. Japanese labels, the application palette, and plain React and CSS replace the original Motion and Lucide dependencies.
